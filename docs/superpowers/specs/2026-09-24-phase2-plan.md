# TyFPJDBC Phase-2 开发计划

- 日期：2026-09-24
- 基线：`docs/superpowers/specs/2026-09-23-tyfpjdbc-design.md`（V1）+ `docs/superpowers/plans/2026-09-23-tyfpjdbc.md`
- 范围：Phase-2，只做可配置化 + PG 语义对齐 + 可观测性，不做新数据库方言，不做 32bit，不做虚拟线程
- 读者：FPC / Lazarus 开发者，Java 门面维护者

## 0. 全局声明

### 0.1 Breaking-change 声明（direct-to-final）

- Phase-2 允许破坏公共 API，无过渡期、无 `deprecated` 兼容层，直接改为终态。
- 涉及破坏的单元：`TyFPJDBC.Connection`（构造签名加参）、`TyFPJDBC.Hikari.Pool`（字段改属性 + 真池）、`TyFPJDBC.Statement`（`ExecUpdate(AffectedHook)` 签名作废）、`TyFPJDBC.Query`（`LoadRowsBuffered` 列数、`ApplyUpdates` 语义）、`TyFPJDBC.Options`（新增必填枚举值）、`TyFPJDBC.JNI.Bridge.TBridgeClient`（方法签名对齐 `Bridge.java`）、`Bridge.java`（`createPool` 参数扩展）。
- 版本握手保持强校验：`BRIDGE_VERSION` 升级到 `2.0.0`，`Pascal` 与 `jar` 不一致直接抛 `EJDBCError(SQLState=HY000, VendorCode=99)`。
- 所有破坏点必须同步改 `examples/ex*.lpr`、`tests/Test*.lpr`、`java/bridge/src/test/java/tyfpjdbc/BridgeTest.java`，CI 全绿才合入。

### 0.2 核心假设

- PG-semantics-first：类型、事务、隔离级别、`RETURNING`、`savepoint`、`::cast`、`$$` 函数体语义以 PostgreSQL 17 为准，其它库做兼容，不为 MySQL/Oracle 特例分支。
- SQLite-zero-deploy：`L0` 冒烟必须保持零部署（`org.xerial:sqlite-jdbc` 单 jar 自带 native），Phase-2 不得引入需手动装 server / native 的默认依赖。H2 保持纯 Java。
- `Core` 零界面依赖不变：`src/core/*.pas` 禁止 `Forms/Dialogs/LCL`，`scripts/guard.ps1` 继续卡点。
- 所有值走绑定、标识符走白名单 `Macro` 的 V1 安全原则不变。

### 0.3 优先级定义

- P0：阻塞 PG 主力场景 / 正确性 / 安全，不做不能发布 Phase-2。
- P1：性能 / 可运维 / 常用 productivity，争取同版本做完。
- P2：体验优化 / 长尾方言，可推迟。

## 1. Connection / DriverRegistry

源文件：`src/core/TyFPJDBC.Connection.pas`，`configs/drivers.json`，`src/tools/mautool.lpr`（无独立 `DriverRegistry` 单元为现状缺陷）。

### 1.1 当前硬编码 / 不可配置点

- `TJDBCConnection.Create` 写死 `AutoCommit=True`、`Isolation=ilReadCommitted`、`ReadOnly=False`，无构造参数。
- 无 `LoginTimeout / SocketTimeout / NetworkTimeout`，V1 spec 要求藏 URL 但未实现。
- 无 `Catalog / Schema` 属性透传。
- `Borrow/Release` 仅布尔翻转，无校验查询、无超时等待。
- `TransactionActive` 单布尔，不支持嵌套，不映射到 JDBC `setAutoCommit/setTransactionIsolation`。
- `Savepoints: TStringList` 纯内存，未委托 `Bridge.savepoint`，与真实 DB 脱节。
- 无 `DriverRegistry` 类：`drivers.json` 只有 `id/maven/driverClass/urlTemplate/testQuery`，无 `UrlBuilder`、无 `extraParams` 合并、无 `Properties` 透传；`Bridge.java` 未设 `driverClassName`，未用 `URLClassLoader` 隔离。

### 1.2 Phase-2 特性

| # | 特性 | 可配置项 + 默认值 | 优先级 | 验收标准 |
|---|---|---|---|---|
| C1 | 真连接参数 + 超时透传 | `LoginTimeoutSecs: Integer = 15`；`SocketTimeoutSecs: Integer = 30`；`NetworkTimeoutMs: Integer = 30000`；`ValidationQuery: string = 'SELECT 1'`；`ValidationTimeoutSecs: Integer = 5` | P0 | `TestLiveBridge` 中设 `LoginTimeoutSecs=2` 连不可达 host 在 ±1s 内报 `08001`；`SocketTimeoutSecs` 透传到 `Properties` 经 `Bridge.getErrorChain` 可见；超时不挂起 CI 超过 10s |
| C2 | 事务语义对齐 PG | `Isolation: TJDBCIsolation = ilReadCommitted` 保留；新增 `IsolationName: string` 只读映射（`READ_COMMITTED` 等）；`ReadOnly: Boolean = False` 下发 `Connection.setReadOnly`；`AutoCommit: Boolean = True` 下发 `setAutoCommit` | P0 | PG 下 `StartTransaction + Savepoint + RollbackToSavepoint` 真实回滚一行；`ReadOnly=True` 后 `INSERT` 报 PG `25006` 且 `Chain` 含 `SQLState`；`ilSerializable` 映射正确 |
| C3 | `Catalog/Schema` 透传 | `Catalog: string = ''`；`Schema: string = ''`（空表示不调用） | P1 | 设 `Schema='public'` 后 `DatabaseMetaData.getTables`（经新增 `Bridge.getTables`）返回限定结果；空值时不额外调用，性能无回归 |
| C4 | `TDriverRegistry` 新单元 | `TDriverRegistry.UrlFor(Id, Host, Port, Database: string; Extra: TStrings): string`；`DefaultPort` 取 `drivers.json:defaultPort`（PG `5432`，H2/SQLite `0`）；`ExtraParams: TJSONObject = {}` 合并为 `?k=v&`；`DriverClass: string` 只读 | P0 | `UrlFor('postgresql','db',5432,'app',nil)='jdbc:postgresql://db:5432/app'`；`UrlFor('sqlite','','','/tmp/a.db')='jdbc:sqlite:/tmp/a.db'`；未知 `id` 抛 `08000`；`mautool --driver postgresql` 输出与该函数一致（单测复用） |
| C5 | 连接校验 + 借用等待 | `BorrowTimeoutMs: Integer = 30000`（复用池 `ConnectionTimeout`）；`TestOnBorrow: Boolean = True`；`TestOnReturn: Boolean = False` | P1 | 池耗尽时按 `BorrowTimeoutMs` 等待后才报 `08001`（不再立即抛）；`TestOnBorrow=True` 时断开连接被剔除并重建，`TestPoolDataset` 通过 |

## 2. JVM.Manager

源文件：`src/core/TyFPJDBC.JVM.Manager.pas`。

### 2.1 当前硬编码 / 不可配置点

- `BuildDesktopArgs='-Xmx512m -Dfile.encoding=UTF-8 -Djava.awt.headless=true'` 写死；`BuildServerArgs='-XX:MaxRAMPercentage=60.0 -Xrs ...'` 写死且无自动选择逻辑。
- `EnsureStarted` 强制要求 `ExtraArgs` 含 `headless=true` 与 `file.encoding=UTF-8`，否则抛错，无结构化选项。
- `SplitArgs` 按空格 `DelimitedText` 切分，不支持引号路径（含空格的 `libjvm` 路径会断裂）。
- `FindLibJvm` 只查 `CustomPath + JAVA_HOME/bin/server/jvm.dll|lib/server/libjvm.so`，不支持自带 `jre/`、`Windows` 注册表、`PATH`、`macOS dylib`。
- 无 `-Xcheck:jni`、`hs_err_pid` 路径、无 `AddModules/EnableAssertions` 选项。
- `FClassPath: string` 单字符串，无多 jar 展开、无 `drivers/*.jar` 通配、无 `URLClassLoader` 配合。
- `JNI_VERSION_1_6` 写死；`FOnLog` 无公开 setter，`DoLog` 实际不可达。
- 无 `GetBridgeVersion` 握手。

### 2.2 Phase-2 特性

| # | 特性 | 可配置项 + 默认值 | 优先级 | 验收标准 |
|---|---|---|---|---|
| J1 | 结构化 `TJVMOptions` | `Mode: TJVMMode = jvmAuto`（`jvmAuto/jvmDesktop/jvmServer`）；`Xmx: string = '512m'`（desktop）；`MaxRAMPercentage: Double = 60.0`（server，范围 50~75 越界抛 `HY092`）；`Headless: Boolean = True`；`FileEncoding: string = 'UTF-8'`；`ExtraArgs: TStringList = 空`；`EnableCheckJNI: Boolean = False`；`HsErrPath: string = './hs_err_pid%p.log'` | P0 | `BuildArgs(Mode=jvmDesktop)` 含 `-Xmx512m` 不含 `-Xrs`；`jvmServer` 含 `-Xrs -XX:MaxRAMPercentage=60.0`；`Headless=False` 抛错提示必须 headless；`EnableCheckJNI=True` 追加 `-Xcheck:jni`；单测覆盖三档字符串快照 |
| J2 | `libjvm` 查找顺序补齐 | `SearchOrder = 'bundled>custom>JAVA_HOME>registry>PATH'` 不可改顺序但可配 `BundledDir: string = 'jre/'`；`CustomPath: string = ''`；`AllowRegistry: Boolean = True`（仅 Windows）；`AllowPath: Boolean = True` | P0 | 无 `JAVA_HOME` 但 `jre/bin/server/jvm.dll` 存在时找到 bundled；Windows 注册表 `HKLM\SOFTWARE\JavaSoft\JDK` 可查；找不到时错误信息列出已试路径；`win64/linux-x64/macos-arm64` 各至少一条 CI/手动记录 |
| J3 | `ClassPath` 多 jar + 引号解析 | `ClassPathEntries: TStringList = ['bridge/tyfpjdbc-bridge.jar','bridge/HikariCP-*.jar','bridge/slf4j-api-*.jar']`；`ExpandDriversDir: Boolean = True`（自动追加 `drivers/*.jar`）；`QuoteAwareSplit: Boolean = True` 默认开启 | P0 | 含空格路径 `C:\Program Files\...\jvm.dll` 不再切断；`drivers/` 新增 jar 重启后 `Class.forName` 可见；`GetClassPath` 返回 `-Djava.class.path=` 全串长度 < 32k 否则抛 `HY092` |
| J4 | 版本握手 + JNI 版本可配 | `ExpectedBridgeVersion: string = '2.0.0'`（取 `BRIDGE_VERSION`）；`JniVersion: Integer = JNI_VERSION_1_6`（允许 `1_6/1_8`）；`HandshakeOnStart: Boolean = True` | P0 | 版本不一致时 `EnsureStarted` 后 `TBridgeClient.GetVersion` 比对失败抛 `HY000/99` 且信息含两边版本号；握手可被 `HandshakeOnStart=False` 跳过（测试专用） |
| J5 | 日志回调公开 | `OnLog: TJVMLogProc = nil` 公开属性；`LogLevel: string = 'INFO'`（透传 `java.util.logging`） | P1 | 赋 `OnLog` 后 `JVM started/reused` 可收到；`EnsureStarted` 失败链写入回调；见 §12 联调 |

## 3. Hikari.Pool

源文件：`src/core/TyFPJDBC.Hikari.Pool.pas`，`src/core/TyFPJDBC.Pool.Intf.pas`，`java/bridge/src/main/java/tyfpjdbc/Bridge.java#createPool`。

### 3.1 当前硬编码 / 不可配置点

- Pascal 默认 `MaximumPoolSize=10, MinimumIdle=2, ConnectionTimeout=30000, MaxLifetime=1800000, KeepaliveTime=30000, LeakDetectionThreshold=0, SlowQueryThresholdMs=1000`，但 `FSlowThresholdMs` 快照后永不同步。
- `Borrow` 为内存 `TList` 模拟：无等待、无 `MinimumIdle` 维持、无 `MaxLifetime` 淘汰、无 keepalive、无 leak 检测。
- `ReleaseConnection` 按 `FIdle.Count < MaximumPoolSize` 回收，否则 `Free`，无 `isValid` 检查。
- `ReportSlow` 需手动调，无自动计时。
- `Bridge.createPool(jdbcUrl,user,pw,maxPool,minIdle)` 仅 5 参，未映射 `connectionTimeout/maxLifetime/keepalive/leakDetection/testQuery/Properties/driverClassName`。

### 3.2 Phase-2 特性

| # | 特性 | 可配置项 + 默认值 | 优先级 | 验收标准 |
|---|---|---|---|---|
| H1 | 真池委托 + 全量 Hikari 映射 | `MaximumPoolSize=10`；`MinimumIdle=2`；`ConnectionTimeoutMs=30000`；`MaxLifetimeMs=1800000`；`KeepaliveTimeMs=30000`；`IdleTimeoutMs=600000`；`ValidationTimeoutMs=5000`；`LeakDetectionThresholdMs=0`（0=关闭）；`ConnectionTestQuery='SELECT 1'`；`DataSourceProperties: TStringList=空`；`DriverClassName: string=''`（空则 ServiceLoader） | P0 | `Borrow` 走 `Bridge.borrowConnection(poolId)` 真连接；`poolStats` 返回 `active/idle/wait` 与 Hikari MXBean 一致；`MaximumPoolSize=1` 时双线程第二借用阻塞后按 `ConnectionTimeoutMs` 超时报 `08001`（不再立即抛） |
| H2 | 空闲维持 / 保活 / 寿命淘汰可配 | 同上 `MinimumIdle/KeepaliveTimeMs/MaxLifetimeMs/IdleTimeoutMs`；`KeepaliveQuery: string = ConnectionTestQuery` | P1 | `MinimumIdle=2` 空闲 60s 后 `IdleCount>=2`；`MaxLifetimeMs=5000` 时长连接 10s 内被轮换（`Borrow` 拿到不同 `connId`）；单测用 H2 不依赖 PG |
| H3 | 慢查询自动计时 | `SlowQueryThresholdMs: Int64 = 1000`（改为实时读属性，删 `FSlowThresholdMs` 快照）；`OnSlowQuery: TSlowQuery = nil`；`AutoTimeFetchBatch: Boolean = True` | P1 | `FetchBatch` 超阈值自动触发 `OnSlowQuery(SQL, ElapsedMs)` 且 `ElapsedMs>=阈值`；阈值改为 1ms 后小查询也触发；`nil` 回调时无崩溃 |
| H4 | 泄漏检测透传 | `LeakDetectionThresholdMs: Int64 = 0`；`OnLeak: TSlowQuery = nil`（复用签名，`SQL='LEAK connId=...'`） | P2 | 设 2000ms 且借用不还超过阈值，Java 日志 + `OnLeak` 触发一次；`0` 时关闭无误报 |

## 4. Statement / Command + Params

源文件：`src/core/TyFPJDBC.Statement.pas`，`src/db/TyFPJDBC.Sql.Parser.pas`。

### 4.1 当前硬编码 / 不可配置点

- `TJDBCStatement` 为模拟器：`ExecUpdate(AffectedHook: Integer): Integer` 直接返回钩子值；`ExecBatch(Count)` 循环 `Sleep`；`FetchBatch` 委托 `OnFetch`。
- 无 `TParam` 绑定：`setString/setInt/setLong/setDouble/setBigDecimal/setDate/setTimestamp/setBinaryStream/setNull` 全缺，`Bridge.execBatch` 全 `setString`。
- `SetQueryTimeout` 仅本地存 `QueryTimeoutSecs`，未下发 `Statement.setQueryTimeout`（`Bridge.execUpdateTimeout` 有但 Pascal 未调）。
- `Cancel` 仅本地 `Cancelled` 标志，未调 `Bridge.cancel`。
- `WaitInterruptible` 轮询 `Sleep(10)` 写死；`ExecBatch` 每 64 行检查一次写死（`i mod 64`）。
- `LIKE ... ESCAPE` 无 helper；`ParameterMetaData` 兜底逻辑无。

### 4.2 Phase-2 特性

| # | 特性 | 可配置项 + 默认值 | 优先级 | 验收标准 |
|---|---|---|---|---|
| S1 | 类型化绑定（Typed binders） | `EnableTypedBinders: Boolean = True`；映射：`ftString/ftWideString/ftWideMemo→setString`，`ftInteger→setInt`，`ftLargeint→setLong`，`ftFloat→setDouble`，`ftBCD/ftFmtBCD→setBigDecimal(字符串中转)`，`ftDate→setDate`，`ftTime→setTime`，`ftDateTime→setTimestamp`，`ftBlob→setBinaryStream`，`Null→setNull(ParameterMetaData类型，取不到按 VARCHAR + 记日志)` | P0 | PG 下 `NUMERIC(30,10)` 经 `ftFmtBCD` 字符串中转精度无损（`10k` 行回读逐行比对）；`DATE/TIMESTAMP` 回读等于写入（±1s 时区说明见 §6）；`NULL` 列 `wasNull→Field.Clear`；注入串 `' OR '1'='1` 原样存不截断 |
| S2 | `QueryTimeout + Cancel` 真下发 | `QueryTimeoutSecs: Integer = 0`（0=不限）；`CancelPollMs: Integer = 10`；`BatchCheckInterval: Integer = 64` | P0 | `SetQueryTimeout(1)` 后 PG `pg_sleep(5)` 报 `HYT00/22`；独立线程 `Cancel` 后 `HY008/21`；`CancelPollMs=1/50` 均不漏检；`BatchCheckInterval` 可配 1~1024 越界抛 `HY092` |
| S3 | `Array DML` 批量大小 | `ArrayDMLBatchSize: Integer = 1000`；`UseServerBatch: Boolean = True`（`addBatch/executeBatch` 单事务，失败全回滚并恢复 `autoCommit`） | P0 | 10k 行 `ExecBatch` 按 1000 切 10 次 `Bridge.execBatch`，总数 `=10000`；中途一坏行全回滚（`SELECT COUNT=0`）；`UseServerBatch=False` 时逐条（仅测试对比用） |
| S4 | `LIKE` 规范 helper | `LikeEscapeChar: Char = '\'`；`RequireLikeEscape: Boolean = True`（文档 + 示例约束，无新 API） | P1 | 示例 `ex02` 改为 `LIKE :kw ESCAPE '\'` + 值内加 `%`；含 `%_\'` 的关键字回读精确匹配；无拼接 helper 新增 |
| S5 | 同名参数双绑保持 | 无新增配置，`ParamOrder: name→indices[]` 语义冻结 | P0 | `WHERE a=:id OR b=:id` 绑定两个 `?` 位；串内 `:id`、`::int`、`:=`、`?|`、`?&` 不误判（`TestParser` 全绿） |

## 5. Query / Dataset

源文件：`src/db/TyFPJDBC.Query.pas`。

### 5.1 当前硬编码 / 不可配置点

- `GEN_KEY_SEED=1000` 写死。
- `LoadRowsBuffered` 只搬 2 列（`Fields[0],Fields[1]`），分隔符 `|` 写死，`ftWideString` 宽度 `255` 写死。
- `LoadRowsLive` 拼接 `SQL + ' LIMIT 1000 OFFSET ' + off` 写死分页 1000，无方言开关、无 keyset 选项。
- `KeyFieldName` 取 `KeyFields` 第一个逗号前，空则 `AutoIncField`，再空则 `Fields[0]`。
- `SqlQuote` 仅单引号 doubling，无标识符引用、无转义。
- `ApplyInsertsLive/ApplyEditsLive` 拼字符串 `INSERT/UPDATE`（值直接进 SQL），未走绑定；`UPDATE` 按 `RowImage(#31/#0)` 全行比对。
- `FetchOptions.Mode=fmOnDemand` 声明了但仍全量缓冲到 `all` 数组；`MaxBufferedRows` 返回 `RecordCount` 无上限。

### 5.2 Phase-2 特性

| # | 特性 | 可配置项 + 默认值 | 优先级 | 验收标准 |
|---|---|---|---|---|
| Q1 | 全列缓冲 + 宽度可配 | `WideStringWidth: Integer = 255`；`MemoAsWideMemo: Boolean = True`；`MaxBufferedRows: Integer = 100000`（超限抛 `HY001` 并提示切 `fmOnDemand`）；`RowDelimiter: Char = '|'`（仅 `LoadRowsBuffered` 兼容老格式用） | P0 | 5 列宽表 `LoadRowsBuffered/LoadJavaRows` 全列到位；超 100k 行 `fmAll` 拒绝并给出切换指引；`WideStringWidth=1024` 后 300 字中文不截断 |
| Q2 | 真 `fmOnDemand` 前向游标 | `FetchOptions.Mode: TFetchMode = fmAll` 保留；`Unidirectional: Boolean = False`（`fmOnDemand` 强制 `True`）；`RowsetSize: Integer = 1000`；`FetchSize: Integer = 1000` 透传 `Statement.setFetchSize` | P0 | `fmOnDemand` 下 1M 行导出内存恒定（Java 堆峰值 < 256MB，`heapUsedBytes` 采样）；`Bookmark` 操作抛明确错；`fmAll` 10k 档性能不回归 |
| Q3 | Live 分页可配 + PG 方言 | `LivePageSize: Integer = 1000`（1~10000）；`LivePaging: TLivePaging = lpLimitOffset`（`lpLimitOffset/lpKeyset`，P2 才做 keyset）；`IdentifierQuote: Char = '"'` | P0 | `LivePageSize=500` 时 `FetchBatch` 调用次数 `=ceil(n/500)`；拼接标识符用 `"` 引用；`LIMIT/OFFSET` 仅 PG/SQLite/H2 路径，文档注明 MySQL 差异不在 Phase-2 |
| Q4 | 可编辑语义补齐 | `UpdateOptions.UpdateMode: TUpdateMode = umWhereKeyOnly`（`umWhereKeyOnly/umWhereChanged/umWhereAll`）；`UpdateOptions.LockMode: TLockMode = lmOptimistic`；`UpdateOptions.RefreshMode: TRefreshMode = rmGeneratedKeys`（`rmGeneratedKeys/rmReturning`）；`UpdateOptions.BatchApplySize: Integer = 1000`；`OnReconcile: TReconcileEvent = nil`（冲突回调）；`GenKeySeed: Int64 = 1000`（替代 `GEN_KEY_SEED` 常量） | P0 | `umWhereKeyOnly` 下 `UPDATE ... WHERE key=?`；并发改同一行第二提交进 `OnReconcile` 且 `affected=0` 不静默丢；`AutoIncField` 经 `getGeneratedKeys`（PG `RETURNING`）回填，`GetGeneratedKeys` 等于 DB 实值；`ApplyUpdates` 走当前连接事务 |
| Q5 | DML 走绑定（去字符串拼接） | `UseParamApply: Boolean = True`（为 False 仅测试对比，默认无拼接） | P0 | `ApplyInsertsLive/ApplyEditsLive` 改走 `ExecBatch/ExecUpdateTimeout` 绑定路径；含单引号/CJK 的值回读一致；`SqlQuote` 仅保留给日志展示，不进执行路径 |

## 6. Type.Map

源文件：`src/db/TyFPJDBC.Type.Map.pas`。

### 6.1 当前硬编码 / 不可配置点

- `ToFieldType` 全写死 if 链，无用户覆盖口。
- `TIMESTAMP WITH TIME ZONE` 粗暴 `Pos('TIMESTAMP',u)=1 → ftDateTime` 丢时区无日志。
- `NUMERIC/DECIMAL` 无条件 `ftFmtBCD`，无精度阈值。
- 缺 `SERIAL/BIGSERIAL/SMALLSERIAL/MONEY/INET/INTERVAL/NAME/OID` 等 PG 常见类型（ fallback `ftWideString` 碰运气）。
- `NeedStream` 仅 `=ftBlob`，无大小阈值；无反向 `FieldType→JDBCType`（`setNull` 兜底用）。

### 6.2 Phase-2 特性

| # | 特性 | 可配置项 + 默认值 | 优先级 | 验收标准 |

## 13. 里程碑顺序（建议 M5→M8）

- M5 地基（P0 地基）：J1–J4 + C4 + B1 + B5 + D1。先让版本握手、JVM 参数、真池建连、错误线程局部立起来，后续都依赖它。出口：`TestLiveBridge(H2)` + 版本 mismatch 单测绿。
- M6 执行与类型（P0 核心）：S1–S3 + T2–T3 + H1 + C1–C2 + B2。参数绑定、超时取消、PG 类型、真池等待。出口：PG 下事务 + NUMERIC + 超时取消 + 池耗尽等待全绿。
- M7 Dataset 与脚本（P0 闭环）：Q1–Q5 + O1/O3 + SC1–SC2 + P1–P2。`ApplyUpdates` 走绑定、`RETURNING` 回填、`Script` 事务语义、存过真调。出口：`ex04_edit_apply` + `ex07_script_migrate` PG 全绿，10k 性能不回归。
- M8 可观测与工具（P1/P2 收尾）：D2–D4 + H2–H4 + B3/B4/B6 + T1/T4 + L1–L3 + O2 + Q2 1M 档 + SC3/P3。慢查询、泄漏、流式、BLOB 阈值、对话框、下载器。出口：`ex06/ex08` 新签名全绿，`mautool --install` 缓存命中，1M 前向导出内存恒定。

约束：M5 不合入不许开 M6 联调；任何 M6+ 需求不得回改 M5 已冻结签名（要改走 breaking 公告重审）。
